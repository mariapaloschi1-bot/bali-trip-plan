# 🌺 Bali Trip Planner

Un'app web moderna e interattiva per pianificare il tuo viaggio a Bali di 7 giorni (11-17 Agosto 2026).

## ✨ Features

- 🗺️ **Mappa interattiva** dell'isola con percorso completo
- 📅 **Itinerario dettagliato** 7 giorni: templi, risaie, spiagge, cultura
- 🏝️ **Database esperienze** con prezzi IDR/EUR
- 💰 **Budget** 3 fasce (€1.420-€8.540)
- 📱 **100% Responsive** mobile-first
- 🎨 **Design tropicale** lilla-rosa
- ℹ️ **Info pratiche** complete

## 🚀 Deploy su Vercel
